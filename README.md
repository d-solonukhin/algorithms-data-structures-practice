# Algorithms & Data Structures in TypeScript

Алгоритмы и структуры данных на TypeScript, чтобы разбирать их в коде, а не только в теории.

## Короткие правила

**Рекурсия.** Нужны базовый случай и шаг, который уменьшает задачу.

**Стек.** LIFO: последний добавленный элемент снимается первым. В реализации на списке `next` смотрит на элемент ниже.

**Разделяй и властвуй.** Разрезать задачу → решить части тем же способом → собрать ответ. Бинарный поиск — первый пример.

## Сложность

| Запись     | Смысл                                  |
| ---------- | -------------------------------------- |
| O(1)       | константное время                      |
| O(log n)   | деление пополам, логарифмическое время |
| O(n)       | один проход, линейное время            |
| O(n log n) | сортировки вроде merge sort            |
| O(n²)      | вложенные циклы                        |
| O(2ⁿ)      | наивная рекурсия с ветвлением          |
